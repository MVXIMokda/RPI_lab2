# Учебная платформа

Учебный сайт на React и Vite: каталог лекторов, курсы и форма заявки.

## Оформление этой версии

Оформление выполнено в минималистичном стиле:

- Градиентная шапка заменена компактной навигацией с названием платформы.
- Использованы светлый фон, тёмный текст, приглушённый зелёный акцент и тонкие границы.
- На главной сокращён заголовок, выделена основная кнопка, фото размещено справа от текста.
- Статистика оформлена одной строкой, блоки «О нас» — без отдельных рамок.
- Уменьшены заголовки карточек, убраны декоративные полосы под портретами и тяжёлые тени.
- Оформление распространено на каталог, профили, курсы и форму; сохранена адаптивная вёрстка.

Внешний макет не предоставлен: выбран спокойный минималистичный стиль на основе существующей структуры.
Маршрутизация, данные, поиск, подсказки и обработка формы сохранены.

## Короткий текст для демонстрации

> В проекте реализован интерфейс учебной платформы на React и Vite. Есть главная страница, каталог лекторов, отдельные профили, каталог курсов, программы дисциплин и форма заявки. Переходы реализованы собственным маршрутизатором через History API. Данные лекторов и курсов вынесены в отдельные JavaScript-файлы, а повторяющиеся элементы — в общие компоненты. Форма проверяет обязательные поля и формат электронной почты, затем показывает подтверждение. Это демонстрация интерфейса: фактической отправки данных на сервер нет.

Порядок показа: главная → «Лекторы» → профиль лектора → «Оставить заявку».
Дополнительно открыть «Курсы», страницу курса и показать проверку полей формы.

## Стек

JavaScript (JSX), CSS, React и React DOM 19.3.0, Vite 8.3.0,
плагин React для Vite 6.1.1, ESLint 10.11.0. Версии зафиксированы в
`package-lock.json`. Требуется Node.js 20.19+ (ветка 20) или 22.12+ и npm.

## Запуск

```bash
npm ci
npm run dev
```

Для запуска вместе с двумя заданиями лабораторной №1 использовать отдельный порт:

```bash
cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-2"
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

Открыть http://127.0.0.1:5175. Остановка — **Ctrl+C** в терминале с работающим сервером.
После остановки повторить эту же команду для нового запуска. `npm ci` перед каждым запуском не требуется.
Закрытие страницы в браузере сервер не останавливает.

Полная [памятка запуска и остановки всех работ](RUNNING.md) находится в этом репозитории.

Команды выполняются из корня проекта. Откройте адрес, который выведет Vite.
Сборка: `npm run build`; просмотр сборки: `npm run preview`;
проверка кода: `npm run lint`.

## Структура

```text
public/          — изображения и favicon
src/
  api/           — формирование ссылок на изображения
  components/    — общие компоненты интерфейса
  data/          — данные лекторов, курсов и партнёров
  hooks/         — React-хуки
  pages/         — страницы и их стили
  router/        — маршрутизатор и ссылки
  styles/        — общие стили
  App.jsx        — маршруты и общий макет
  main.jsx       — точка входа
index.html       — HTML-шаблон
vite.config.js   — настройки сборки
```

## Реакция на изменение размера окна

Ширина окна хранится в состоянии хука `src/hooks/useWindowWidth.js`.
Внутри `useEffect` хук подписывается на событие `resize` браузера, а
возвращаемая функция очистки снимает обработчик. После размонтирования
компонента `window` не хранит ссылку на его состояние, поэтому утечки
памяти нет.

Хук использует `NavBar`: при ширине меньше 768px навигация переходит в
компактный режим — появляется кнопка «Меню», а ссылки скрываются и
раскрываются по нажатию. Открытое меню закрывается по Escape и после
перехода по ссылке; при возврате широкого окна ссылки показываются снова.

Как проверить: сузить окно до 768px и меньше — навигация переключится;
растянуть обратно — вернётся обычный вид. В DevTools → Elements →
Event Listeners (на `window`) виден один обработчик `resize`.

## Данные и маршрутизация

Данные хранятся в `src/data/lecturers.js`, `courses.js` и `partners.js`.
Изображения загружаются из Yandex Cloud; ссылки заданы в `src/api/photos.js`,
дополнительная настройка не нужна. Локальные копии находятся в `public/`.

Маршруты объявлены в `src/App.jsx`, маршрутизатор реализован в `src/router/`
через History API. Страницы: `/`, `/lecturers`, `/lecturers/:id`, `/courses`,
`/courses/:id`, `/contacts`; неизвестные адреса открывают страницу 404.
