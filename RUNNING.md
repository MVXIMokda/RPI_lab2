# Памятка: запуск и остановка всех приложений

Каждое приложение запускается в отдельной вкладке терминала. На macOS новую вкладку обычно открывают сочетанием Cmd+T.
Если терминал показывает адрес Vite и больше не выводит приглашение ввода, сервер работает — эту вкладку нужно оставить открытой.

### Установка зависимостей — только при первом запуске или после их изменения

```bash
cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-1"
npm ci

cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-2"
npm ci
```

Повторять `npm ci` перед каждым запуском не нужно. Зависимости первого задания и второго задания лабы №1 устанавливаются вместе из `lab-1`.

### Терминал 1 — лаба №1, задание 1

```bash
cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-1"
npm run dev:task1
```

Открыть: http://127.0.0.1:5173.

### Терминал 2 — лаба №1, задание 2

```bash
cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-1"
npm run dev:task2
```

Открыть: http://127.0.0.1:5174.

### Терминал 3 — лаба №2

```bash
cd "$HOME/ВУЗ/4 курс/Development_user_interface/lab-2"
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

Открыть: http://127.0.0.1:5175. Все три сервера доступны только с этого компьютера.

## Как остановить и запустить заново

1. Открыть вкладку терминала, в которой работает нужный сервер.
2. Нажать **Ctrl+C** — именно Control, а не Command. Выделение текста для этого не требуется.
3. Дождаться обычного приглашения ввода команд: сервер остановлен.
4. Чтобы остановить все приложения, повторить в трёх вкладках.
5. Для повторного запуска выполнить ту же команду `npm run ...` в нужной папке. Переустанавливать зависимости не нужно.

Закрытие вкладки браузера не останавливает сервер. При обычном редактировании исходников Vite обновляет страницу автоматически — перезапускать сервер для каждой правки не нужно.

## Ошибка: Port 5173 is already in use

Она означает, что на этом порту уже работает другой сервер. Для 5174 и 5175 действия такие же.
`Re-optimizing dependencies because lockfile has changed` — информационное сообщение Vite, а не причина ошибки.

Сначала открыть http://127.0.0.1:5173: возможно, нужная лаба уже запущена и повторный запуск не нужен.
Чтобы перезапустить её, остановить старый сервер через Ctrl+C в его терминале.

Если старую вкладку терминала найти не получается, определить процесс:

```bash
lsof -nP -iTCP:5173 -sTCP:LISTEN
```

В столбце PID будет номер процесса. Проверить его рабочую папку, подставив фактический номер вместо `12345`:

```bash
lsof -a -p 12345 -d cwd
```

Если это папка нужной лабы, остановить именно этот процесс:

```bash
kill -TERM 12345
```

Номер `12345` — пример, его нельзя копировать без замены. После остановки повторить обычный запуск.
Не нужно завершать все процессы Node: среди них могут быть другие проекты.
